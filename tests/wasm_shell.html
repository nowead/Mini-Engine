Mini-Engine

WebGPU · WebAssembly · Real-time

A deferred renderer running entirely in the browser — no plugins, no native code. The G-Buffer pass separates geometry from lighting so multiple dynamic lights cost almost nothing extra. PBR + IBL, PCSS soft shadows, SSAO, and Bloom, all at 60 fps via the WebGPU API.
